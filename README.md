# Axphonenum
A tool to get information by phone number | by axom. 

- requirements
```pip install phonenumbers>=8.13.0```
```pip installgooglesearch-python>=1.2.0```
```pip install requests>=2.28.0```

- usage
```cd ~```
```rm -rf axphonenum```
```git clone https://github.com/axomtools/axphonenum.git```
```cd axphonenum```
```pip install -r requirements.txt```
```python main.py```
